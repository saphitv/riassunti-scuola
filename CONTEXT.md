# School Summaries

This context describes the language used to organize personal university study material by subject, semester, and test-oriented summaries.

## Language

**Riassunto**:
A printable study summary for a course or course test.
_Avoid_: Resume, note page

**Parte**:
A separately browsable portion of a riassunto when one course is split across multiple test scopes.
_Avoid_: Duplicate course, volume

**Semestre**:
The academic semester associated with a course or test scope.
_Avoid_: Term
